# SISTEM DATA MAHASISWA

## Deskripsi Project

Sistem Data Mahasiswa merupakan aplikasi sederhana berbasis Python yang dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS) mata kuliah Pemrograman Berorientasi Objek (OOP).

Program ini digunakan untuk mengelola data mahasiswa seperti NIM, nama, dan nilai.

## Fitur Program

1. Menambahkan data mahasiswa.
2. Menampilkan seluruh data mahasiswa.
3. Mengubah nilai mahasiswa.
4. Menghitung rata-rata nilai.
5. Menampilkan jumlah mahasiswa.

## Konsep Object-Oriented Programming

Project ini menerapkan beberapa konsep OOP, yaitu:

- Class dan Object
- Constructor (**init**)
- Attribute dan Method
- Encapsulation
- Property dan Setter
- Class Method
- Static Method

## Teknologi

- Bahasa Pemrograman: Python
- Versi Python: 3.13.14
- Editor: Visual Studio Code

## Cara Menjalankan

1. Pastikan Python sudah terinstal.
2. Buka folder project di VS Code.
3. Buka terminal.
4. Jalankan perintah:

python main.py
